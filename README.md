# 🚀 SocialSync

**SocialSync** is an AI-powered full-stack social media management platform that helps users create, organize, and schedule content across multiple social media accounts. The platform leverages Artificial Intelligence to generate engaging post captions and images, making content creation faster, smarter, and more efficient.

---

## 🌟 Features

- 🔐 Secure User Authentication (JWT)
- 👤 User Registration & Login
- 📱 Manage Multiple Social Media Accounts
- 🤖 AI-Powered Caption Generation
- 🎨 AI Image Generation
- 📅 Schedule Social Media Posts
- 📝 Create, Edit & Delete Scheduled Posts
- ☁️ Cloudinary Image Upload Integration
- 📊 User Dashboard
- ⚡ Responsive User Interface
- 🔄 Automated Social Media Workflow

# ⚙️ Environment Variables

Create a `.env` file inside the `server` directory.

```env
MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_secret_key

GEMINI_API_KEY=your_gemini_api_key

LEONARDO_API_KEY=your_leonardo_api_key

ZERNIO_API_KEY=your_zernio_api_key

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_API_KEY=your_cloudinary_api_key

CLOUDINARY_API_SECRET=your_cloudinary_api_secret
```

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/PranjitaModi/SocialSync.git
```

Navigate to the project directory:

```bash
cd SocialSync
```

Install backend dependencies:

```bash
cd server
npm install
```

Install frontend dependencies:

```bash
cd ../client
npm install
```

---

# ▶️ Run the Application

### Start Backend

```bash
cd server
npm run server
```

Backend runs at:

```
http://localhost:3000
```

---

### Start Frontend

```bash
cd client
npm run dev
```

Frontend runs at:

```
http://localhost:5173
```
